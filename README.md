# Downloads do e-KHEP

Instaladores do aplicativo e-KHEP.

Acesse https://ekhep.vercel.app/downloads pelo painel ou consulte as Releases deste repositório.

Este repositório contém apenas arquivos de distribuição; o código da aplicação é privado. Os pacotes desktop iniciais ainda não têm certificado de assinatura; os pacotes Mac são para testes.
